# A ‘multiscale’ assessment of the molecular mechanisms related to the pro-survival Bcl-2 proteins in breast cancer

This is repository encompassing the data and analysis applied in this study.

The study was conducted accordingly:

1. [Identification of BCL-2 interaction partners containing the BH-3 motif](bcl2_protein_interactions/README.md)
2. [Differential expression analyses of the Cancer Genome Atlas (TCGA) RNASeq BRCA dataset](tcga_brca_dea/README.md)
3. [Retrieval of mutations mapping our genes of interest](mutations/README.md)
4. [Homology modelling of protein-peptide interactions](modelling/README.md)
5. [Structure-Based Prediction of the Functional Impact of BH3 Mutations](add)

## To reproduce this analysis

Clone this directory and subsequently follow the steps detailed in the README's of the subdirectories.

```
$ git clone https://github.com/ELELAB/bcl2_bh3_breast_cancer.git
```
